# Nearby Job Finder

Android APK downloads.

## Install

1. Open the latest release below and download `nearby-job-finder.apk`.
2. Open the downloaded APK on your Android phone.
3. If Android asks, open Settings and allow "Install unknown apps" for the browser or file manager you used. Only allow this if you trust this download.
4. Return to the APK and tap Install.
5. After installing, turn off "Allow from this source" again.

This repository contains downloads and install instructions only.
